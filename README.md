# Pool Architect 3D

Create the architecture of a premium 3D Swimming Pool Configurator integrated into the current website.

Do NOT create a simple form.

Create a real software experience.

The configurator must use React Three Fiber (Three.js).

The swimming pool must be a REAL 3D object.

No static images.

No fake renders.

The user must be able to:

• Rotate

• Zoom

• Pan

The 3D pool must update instantly after every modification.

The geometry must remain perfectly proportional.

Create the following steps:

STEP 1

Project Type

• New Pool

• Pool Renovation

STEP 2

Customer Information

Name

Surname

Email

Phone

City

Province

Country

STEP 3

Pool Shape

Rectangle

Custom Shape

Immediately regenerate the pool geometry.

STEP 4

Dimensions

Length

Width

Depth

Automatically calculate:

• Water Volume

• Internal Surface

• Floor Surface

• Wall Surface

• Perimeter

Every dimension must immediately resize the 3D model.

Create the project using reusable React components.

No duplicated code.

No hardcoded values.

Everything must be production ready.

Do NOT create prices.

Do NOT generate quotations.

The configurator is only for collecting project information.
